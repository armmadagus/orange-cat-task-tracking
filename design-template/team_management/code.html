Orange Cat Standard RBAC
shield

Admin (ผู้ดูแลระบบ)

สิทธิ์ควบคุมสูงสุด
  • check_circle สร้าง ลบ และแก้ไข Workspace / โครงการ
  • check_circle เชิญสมาชิก ปรับระดับ Role หรือนำสมาชิกออก
  • check_circle จัดการ Task เต็มรูปแบบ (CRUD) และลบงานผู้อื่น
  • check_circle เข้าถึง Billing, Audit Log และการตั้งค่าระบบ
เหมาะสำหรับ Tech Lead, PM, หรือ Workspace Owner
person

Member (สมาชิกทั่วไป)

สิทธิ์ระดับปฏิบัติการ
  • check_circle สร้าง ปรับสถานะ ลากจัดลำดับการ์ด (Drag & Drop)
  • check_circle เพิ่มและแก้ไข Subtasks, Due date, Labels
  • check_circle เขียน Comment และแนบไฟล์บน Task
  • cancel ไม่สามารถลบ Project หรือจัดการสิทธิ์คนอื่น
เหมาะสำหรับ Developer, Designer, QA, Marketer
visibility

Guest (ผู้เข้าชม)

อ่านอย่างเดียว (Read-only)
  • check_circle เข้าดู Kanban board, Timeline, Gantt ได้ทุกมุมมอง
  • check_circle ดูรายละเอียดงาน กำหนดส่ง และผู้รับผิดชอบ
  • cancel ไม่สามารถลากย้ายการ์ดหรือเปลี่ยนสถานะ
  • cancel ไม่สามารถสร้างหรือลบงานใดๆ ในระบบ
เหมาะสำหรับ Product Owner, ลูกค้า, หรือ External Auditor
